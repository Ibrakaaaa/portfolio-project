What happens when you open this site

This page runs on a server I set up and maintain. Here is the path a request takes, and the path a code change takes before it reaches you.

A request

  1. Your browser

    Asks for ibrahimmerkez.com over HTTPS.

  2. Nginx

    Handles the TLS certificate from Let's Encrypt, which renews itself, and decides where each request goes.

  3. React container Express container

    Pages come from the React build. Anything under /api goes to the Node.js API.

  4. MongoDB Atlas

    Stores the data. The database credentials live only on the server, never in the code.

Live check: asking the API…

A change

  1. Pull request

    Every change goes through a branch and a pull request to main.

  2. GitHub Actions

    Builds the backend and frontend Docker images, so a broken build shows up before it is merged.

  3. Merge to main

    Starts a deploy job that connects to the server over SSH with a dedicated deploy key.

  4. Hetzner server

    A deploy script rebuilds the containers and restarts the stack with Docker Compose.
